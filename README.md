# Everclick Core releases

`latest.json` names the newest published version of Everclick Core. Each Everclick website reads it
to show on its status page whether an update is available.

```json
{ "core": "1.4.0", "released": "2026-11-02", "security": false, "note": "One line about the release" }
```

This repo holds only that file. It's updated automatically when a new version is published; please
don't edit it by hand.
